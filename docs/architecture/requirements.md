# Требования, противоречия и ограничения

Сводная спецификация функциональных и нефункциональных требований проекта **NexDeck**, а также выявленные технические ограничения.

---

## 1. Нефункциональные требования

| ID | Требование | Целевой ориентир |
| --- | --- | --- |
| `NFR-01` | Потребление RAM в простое | **2–5 МБ** для минимальной конфигурации фонового `Core Agent` (измеряется на release-сборках) |
| `NFR-02` | Нагрузка на CPU | Минимальное потребление в простое; асинхронная обработка событий |
| `NFR-03` | Фоновый процесс без GUI | В `nexdeck-agent` не линкуются графические движки и WebView |
| `NFR-04` | Экономия трафика | Передача только необходимых показателей и изменений |
| `NFR-05` | Минимум зависимостей | Компактные бинарные файлы и жёсткий контроль графа крейтов |
| `NFR-06` | Основная ОС хоста | Windows 11 (`x86_64-pc-windows-msvc`), автозапуск, работа при выключенном мониторе |
| `NFR-07` | Мобильные платформы | Android и iOS на единой кодовой базе Flutter |
| `NFR-08` | Безопасность | Авторизация устройств, права `deny-by-default`, защита от повтора запросов, песочница плагинов, без подмены UAC |
| `NFR-09` | Лицензионная чистота | Apache License 2.0 с автоматическим контролем зависимостей в CI |

## 3. Выявленные противоречия и инженерные ограничения

1. **Бюджет 2–5 МБ RAM против рантаймов расширений:**  
   Встраивание JS-движка или интерпретатора Python в фоновый процесс сразу превысит бюджет памяти. Решение: ядро остаётся на чистом Rust, основной формат плагинов — **WebAssembly** ([ADR-0004](adr/0004-plugin-engine-wasm.md)) с ленивой загрузкой, а тяжёлые внешние скрипты могут подключаться только как отдельные процессы через Universal API.
2. **Аппаратные датчики Windows 11 без тяжёлых зависимостей:**  
   Чтение температур CPU/GPU и оборотов вентиляторов часто требует вендорных API или привилегированных драйверов. Решение: использовать лёгкие нативные Win32/PDH API через трейт `MetricCollector`, вынося расширенные сенсоры в опциональные модули.
3. **Уведомления во время сна ПК:**  
   Во время сна Windows агент не может удерживать локальный WebSocket без отдельного облачного push-шлюза. Решение: ограниченная очередь `NotificationQueue` сохраняет события и доставляет их после пробуждения и переподключения.
4. **Remote Approval и Windows UAC:**  
   Подтверждение на телефоне не заменяет и не обходит системный UAC Windows — подтверждения работают в пределах прав агента и зарегистрированных интеграций.
5. **Кроссплатформенная сборка iOS:**  
   Сборка iOS-клиента на Flutter требует macOS-раннера и Xcode; для Android достаточно Linux/Windows.
