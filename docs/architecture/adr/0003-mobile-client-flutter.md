# ADR-0003: Flutter для мобильного клиента

- **Статус:** Принято
- **Дата:** 2026-11-17

## Контекст

Требуется единое мобильное приложение для **Android** и **iOS**, поддерживающее настраиваемые сетки виджетов, графики в реальном времени, уведомления и диалоги подтверждения.

## Решение

Использовать **Flutter** в каталоге `apps/mobile` с подключением к `Core Agent` через абстракцию `nexdeck-transport` (Wi-Fi WebSocket в MVP, USB и Bluetooth на Этапе 7).

## Последствия

- **Плюсы:** единая кодовая база для Android и iOS, плавный рендеринг интерактивных панелей и виджетов.
- **Минусы:** на Этапе 2 потребуется установка Flutter SDK и настройка macOS-раннера в CI для сборки iOS.
