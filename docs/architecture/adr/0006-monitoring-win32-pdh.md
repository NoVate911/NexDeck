# ADR-0006: Нативный мониторинг Windows 11 на базе `windows-sys` (Win32 / PDH)

- **Статус:** Принято
- **Дата:** 2026-11-17

## Контекст

Фоновый процесс `nexdeck-agent` должен собирать базовые метрики (`CPU`, `RAM`, `Disk`, `Network`, `Battery`, `Uptime`) с минимальными аллокациями, без WMI-утечек памяти и с минимальным числом сторонних зависимостей.

## Решение

1. Реализовать сборщик метрик для Windows 11 непосредственно поверх **`windows-sys`** (только точечно включённые фичи Win32 API / PDH / IP Helper).
2. Изолировать весь `unsafe`-код FFI в закрытом платформенном модуле внутри `crates/monitoring` с безопасными RAII-обёртками; все остальные крейты workspace сохраняют `#![forbid(unsafe_code)]`.
3. Для кроссплатформенной разработки, unit-тестов и CI на Linux предусмотреть чистый тестовый/портативный адаптер под интерфейсом `MetricCollector`.

## Последствия

- **Плюсы:** минимальное потребление RAM и предсказуемое время выборки, отсутствие лишних транзитивных зависимостей.
- **Минусы:** расширенные датчики температур/GPU в будущих этапах потребуют отдельных адаптеров (NVML / D3DKMT / внешний опциональный коллектор).
