# ADR-0002: Desktop Manager на чистом Rust UI

- **Статус:** Принято
- **Дата:** 2026-11-17

## Контекст

Необходима отдельная графическая оболочка настройки Windows 11 (`apps/desktop`) без утяжеления фонового агента и без встраивания браузерных движков.

## Решение

1. Разрабатывать `nexdeck-desktop` на **чистом Rust UI** (`egui` или `slint`; окончательный выбор крейта — на старте Этапа 1/3).
2. Вынести GUI в отдельный процесс, взаимодействующий с `nexdeck-agent` через локальный IPC / Universal API.

## Последствия

- **Плюсы:** отсутствие зависимостей WebView2/Node.js, малый размер дистрибутива, единая модель данных на Rust и нулевая нагрузка на фонового агента при закрытом окне настроек.
- **Минусы:** визуальный редактор панелей потребует больше собственной UI-логики на Rust, чем HTML-канвас.
