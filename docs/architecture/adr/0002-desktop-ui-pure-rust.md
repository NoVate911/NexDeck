# ADR-0002: Desktop Manager на чистом Rust UI (`egui / eframe`)

- **Статус:** Принято
- **Дата:** 2026-11-17

## Контекст

Необходима отдельная графическая оболочка настройки Windows 11 (`apps/desktop`) без утяжеления фонового агента, без встраивания браузерных движков и с полной совместимостью с лицензией `Apache-2.0`.

## Решение

1. Разрабатывать `nexdeck-desktop` на чистом Rust UI с использованием **`egui` / `eframe`** (лицензия `MIT OR Apache-2.0`).
2. Вынести GUI в отдельный процесс, взаимодействующий с `nexdeck-agent` через локальный IPC / Universal API.

## Последствия

- **Плюсы:** полная лицензионная совместимость с `Apache-2.0`, отсутствие WebView2/Node.js, компактный бинарник, встроенная поддержка графиков и быстрая разработка утилит настройки.
- **Минусы:** визуальный редактор панелей строится на собственной логике поверх `egui`, а не на HTML-канвасе.
