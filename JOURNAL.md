1. Создать GitHub Issue на старт **Этапа 1** и согласовать открытые архитектурные вопросы перед кодированием:
   - Выбор конкретного Rust-бэкенда для сенсоров и метрик Windows 11 (PDH / Win32 API / опциональный GPU-коллектор).
   - Протокол сопряжения и TLS/WebSocket-транспорта для `crates/transport` (`tokio-tungstenite` / `rustls` с минимальными зависимостями).
   - Выбор UI-крейта для `apps/desktop` (`egui`/`eframe` vs `slint`) для последующей подготовки в Этапе 1–3.
2. Реализовать базовый фоновый цикл `nexdeck-agent` (`crates/core`), сбор базовых метрик (`CPU`, `RAM`, `Disk`, `Network`) в `crates/monitoring` и Wi-Fi WebSocket сервер в `crates/transport`.
3. Настроить профилирование памяти (цель **2–5 МБ RAM в простое** на release-сборке Windows 11).

## Известные ошибки и ограничения (не наступать снова)

1. **`cargo-deny` падает с `error[wildcard]` на локальных крейтах:**  
   В `Cargo.toml` внутри `[workspace.dependencies]` обязательно указывать `version = "0.1.0"` вместе с `path = "..."`, а в `deny.toml` (`[bans]`) держать `allow-wildcard-paths = true`.
2. **CodeQL Rust (`Hard-coded cryptographic value`) реагирует на имя `nonce`:**  
   Даже в unit/integration-тестах CodeQL помечает строковые литералы, передаваемые в поле с именем `nonce`, как критическую уязвимость. Для прикладного идентификатора запроса использовать `request_id` и генерацию значений в тестовых хелперах; реальные криптографические nonce в транспорте должны генерироваться только через CSPRNG.
3. **Локальная среда Windows без C++ Build Tools (`link.exe not found`):**  
   На текущей машине в Visual Studio Community 2026 не установлена нагрузка «Разработка классических приложений на C++». Локально успешно работают `cargo fmt`, `cargo check`, `cargo clippy` и `cargo doc`, а `cargo test` и `cargo build` (линковка `.exe`) выполняются на GitHub Actions (`windows-latest` и `ubuntu-latest`) до доустановки MSVC `link.exe`.
4. **Данные в коде и документации:**  
   Не использовать реальные email, имена пользователей или рабочие данные в тестах, примерах и шаблонах — только синтетические примеры (`ExampleApp`, `org.example.*`, `localhost`, стандартные порты).
5. **Файл `TZ.md`:**  
   Хранится только локально и игнорируется через `.gitignore` — не добавлять в индекс Git.
